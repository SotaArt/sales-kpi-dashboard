# Sales KPI Dashboard

Автоматизация KPI-отчётности и ежедневной планёрки («летучки») отдела продаж в **Google Sheets**:
Apps Script + Google Sheets API + HTML-дашборды.

> Демо-версия: все данные, имена и расчёты в этом репозитории — **вымышленные**.
> Реальная таблица, боевые скрипты и служебные материалы в открытый доступ не выкладываются.

## Зачем это было нужно

Отдел живёт в одной большой Google-таблице: персональные листы менеджеров, статистика,
планирование на день, новости, обучение, витрина «кто кого должен обзвонить». Ежедневно
руками собирать из этого сводку — дорого и с ошибками.

Система «Летучка» вытягивает данные из таблицы и собирает живую планёрку:
- утренняя карточка дня: план РКО / факт / оттоки / встречи по каждому менеджеру;
- доска «Планирование»: запись задач на день прямо с формы;
- лента новостей за N дней;
- статусы обработки («ОС») и заголовки без ошибок формул (`#REF!`, `#N/A` и т.п. превращаются в пустоту).

## Структура

```
appsscript/            # бэкенд для развёртывания в Apps Script (веб-приложение)
├── News.gs            #   GET ?days=N — лента новостей
└── Планирование.gs    #   POST {row:[…]} — запись задачи дня в лист «Планирование»
scripts/
├── core-payload.js    # общая логика построения payload-данных (главный модуль)
├── package.json       # зависимости (googleapis)
└── config.example.json# шаблон конфига (копируется в config.json, в git не попадает)
data/
└── example-planerka.csv  # демо-выгрузка «Планирования» (вымышленные данные)
```

## Как это работает

Один и тот же `core-payload.js` используется в двух средах:

```
Google Sheets (значения) ──> core-payload.js ──> JSON-дашборд (HTML)
                              │        │
                        локально      в Apps Script
                      (serve.mjs)     (Api.gs, doGet/doPost)
```

- **Локально** — Node.js: чтение таблицы через `googleapis` (OAuth), отдача JSON.
- **В Apps Script** — тот же код вклеивается сервером, но читает таблицу через
  `SpreadsheetApp.getActiveSpreadsheet()`.

Числовая «чистка»: формулы с ошибками (`#REF!`, `#DIV/0!`…), прочерки и пустые ячейки
схлопываются в `null`/пустую строку — дашборд не ломается от битых формул.

## Установка (локальный запуск)

```bash
cd scripts
npm install
cp config.example.json config.json   # вписать свои OAuth-данные (см. ниже)
npm run auth                          # один раз получить токен
node serve.mjs                        # http://127.0.0.1:8080
```

Конфиг получается в Google Cloud Console: включить Google Sheets API → создать
OAuth-клиент (Desktop app) → скопировать `client_id` / `client_secret` в `config.json`.
Файлы `config.json`, `token.json` и любые `client_secret*` исключены из git (`.gitignore`).

## Развёртывание в Apps Script

1. Открыть свою таблицу → Расширения → Apps Script.
2. Добавить файлы `News.gs`, `Планирование.gs` (и, при желании, сборку `Api.gs` из `core-payload.js`).
3. Развернуть как веб-приложение (выполнение «Я», доступ — в контуре организации).
4. URL веб-приложения указать в дашборде как `API_ENDPOINT`.
